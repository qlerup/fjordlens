# Musik til Fjordlens

Her kan du lægge baggrundsmusik til momenter som MP3- eller WAV-filer.

Brug gerne beskrivende filnavne, fx `vores-dag.mp3` eller `sommerminder.mp3`.
Tilføj kun musik, som du har rettigheder til at dele her.

Mappen er klar til musikfiler. Afspilning som baggrundsmusik i Fjordlens
skal tilføjes særskilt.
